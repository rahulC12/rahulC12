# Hi, I'm Rahul 👋

Software Engineer working at the intersection of test automation and applied ML. I build tooling for firmware testing and lab automation, and I'm increasingly applying ML/LLMs to make that infrastructure smarter — anomaly detection in test results, automated log analysis, and reducing the manual triage load on large test suites.

## What I work on

- **ML/LLMs for test infrastructure** — applying anomaly detection to test result data and using LLMs to parse and summarize logs, cutting down manual triage time on large automated test runs
- **Automated test infrastructure** for embedded firmware — designing and debugging NI TestStand sequences, handling protocol-level edge cases (retries, timing, malformed packets) that only show up under real-world conditions
- **Remote lab automation** — Python services that dispatch and track tasks (software upgrades, config restores, health checks) across a fleet of Windows lab machines
- **Full-stack internal tooling** — Angular/C#/FastAPI applications for managing test infrastructure, with a focus on clear error handling and notification UX for long-running background jobs
- **Network protocol analysis** — extracting and working with ZigBee network/link keys, filtering and inspecting captures with Wireshark/tshark
