Software Engineer working at the intersection of test automation and applied ML. I build tooling for firmware testing and lab automation, and I apply ML and LLMs to make that infrastructure smarter — computer-vision models that read instrument displays, anomaly detection in test results, and automated log analysis that cuts manual triage on large test suites.

> 💼 **Open to freelance work** in Python automation, API/backend services, and AI integration.

## What I work on

- **Computer vision in production** — trained and deployed custom YOLOv5/YOLOv8 detection models that read digital instrument displays, replacing manual screen reading during automated test runs
- **ML/LLMs for test infrastructure** — anomaly detection over test result data and LLM-based log parsing and summarisation, cutting manual triage time on large automated runs
- **Automated test infrastructure** for embedded firmware — designing and debugging NI TestStand sequences, handling protocol-level edge cases (retries, timing, malformed packets) that only surface under real-world conditions
- **Remote lab automation** — Python/FastAPI services that dispatch and track long-running tasks (software upgrades, config restores, health checks) across a fleet of Windows lab machines
- **Full-stack internal tooling** — Angular/C#/FastAPI applications for managing test infrastructure, with a focus on clear error handling and notification UX for background jobs
- **Network protocol analysis** — working with ZigBee network and link keys, filtering and inspecting captures with Wireshark/tshark
